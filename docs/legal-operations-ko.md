# COMPIVOX 정책 문서 운영 체크리스트

정책 문서는 `web/privacy.html`, `web/terms.html`, `web/service-information.html`, `web/legal-information.html`, `web/faq.html`에서 제공하며 Cloudflare Worker가 확장자 없는 URL로 연결합니다.

## 게시 전 운영자 확인

- 운영 주체의 법적 성명 또는 상호, 주소, 개인정보 보호책임자
- 개인정보 열람·정정·삭제 요청과 일반 문의를 받을 비공개 연락처
- Cloudflare, Render 및 선택적 IP 위험정보 제공자의 실제 계약 법인, 처리 지역, 위탁·국외 이전 항목과 보유기간
- 실제 운영 배포 여부, D1·Render 접근 통제, DB·플랫폼 로그 및 백업 보유기간
- 기존 계정 DB에 과거 이메일 주소가 남아 있는지, 삭제·파기 요청을 실행할 절차
- 만 14세 미만 이용자의 법정대리인 동의와 확인 기능을 도입할지 여부
- 상품 판매 전 사업자 표시, 결제·구독 설명, 청약철회 및 환불 정책

확인 전에는 해당 항목을 사실처럼 채우지 않습니다. GitHub 이슈는 공개될 수 있으므로 개인정보 요청 접수처로 사용하지 말고, 비공개 채널을 별도로 마련해야 합니다.

## 정책 버전 변경

- 현재 페이지 최초 시행 버전은 `2026-11-02`입니다.
- 새 버전을 시행할 때 정책 본문을 수정하고, 이전 시행본을 `/policy-archive/YYYY-MM-DD/` 경로에 보존하여 이용자가 확인할 수 있게 합니다.
- `server/src/services.js`의 `POLICY_VERSION`과 `policy_acceptances`의 terms/privacy 버전, 가입·재동의 화면 설명 및 페이지의 시행일을 같은 배포에서 함께 갱신합니다.
- 기존 계정은 로그인 후 새 버전에 동의하기 전까지 인증된 기능을 이용할 수 없으며, 이전 기록은 새 동의 시각으로 갱신됩니다.

정책 동의 DB 테이블은 계정별 이용약관 버전, 개인정보 처리방침 버전, 동의 시각만 저장합니다. 이전 정책 본문을 자동 보존하지 않으므로 새 버전을 배포할 때 이전 문서를 `/policy-archive/YYYY-MM-DD/` 경로에 별도 보관하고 링크해야 합니다. 현재 사이트에는 과거 문서 아카이브가 아직 없습니다.
