자주 묻는 질문

기준일: 2026년 11월 2일

아래 답변은 저장소에서 확인할 수 있는 기능을 설명하며, 개별 사안에 대한 법률 판단이나 보안 인증을 뜻하지 않습니다.

목차

    1. 미성년자가 이런 프로그램을 개발해도 되나요?

    개발 또는 웹사이트 제작이 미성년자라는 이유만으로 자동으로 불법이 되는 것은 아닙니다. 다만 운영·계약·결제·영업·개인정보 처리에는 별도의 법률과 계약 조건이 적용될 수 있습니다. 구체적인 활동을 시작하기 전에 법정대리인과 전문가에게 확인하십시오. 미성년자·법률 안내를 참고하세요.

    2. 만 14세 미만이 웹사이트를 운영해도 되나요?

    연령만으로 단정할 수 없습니다. 다만 만 14세 미만 아동의 개인정보를 처리할 때 개인정보 보호법상 법정대리인 동의·확인 요건이 적용됩니다. COMPIVOX 가입에는 나이 확인이나 법정대리인 동의 기능이 아직 없어, 만 14세 미만 이용자는 해당 절차가 마련되기 전 계정을 만들지 않아야 합니다.

    3. 프로그램을 판매하는 것이 불법인가요?

    프로그램 판매의 적법성은 운영자의 계약능력·사업 구조, 판매자 정보, 소비자 보호, 세금 및 지식재산권 등 여러 사실에 따라 달라집니다. 미성년자라는 이유만으로 일률적으로 불법이라거나 아무 제한 없이 가능하다고 답할 수 없습니다. 현재 COMPIVOX에는 온라인 결제나 상품 판매 기능이 연결되지 않았습니다.

    4. 개인정보를 수집해도 되나요?

    수집 목적과 법적 근거를 정하고 필요한 최소한의 항목을 처리하며, 적절한 고지·보호·보유기간·권리 요청 절차를 마련해야 합니다. 특히 만 14세 미만 아동 정보와 국외 이전은 추가 요건을 검토해야 합니다. COMPIVOX는 가입 아이디, 비밀번호 해시, IP, 세션·기기·보안·빌드 이용 정보를 처리합니다. 이메일은 신규 가입 화면에서 요구하지 않지만 기존 DB에 이메일 열이 남아 있어 운영자 확인이 필요합니다. 자세한 내용은 개인정보 처리방침을 보십시오.

    5. Device ID와 IP 주소를 사용하는 이유는 무엇인가요?

    코드상 Device ID는 설치를 계정에 연결하고 계정별 기기 수와 빌드 권한을 확인하는 데 사용됩니다. IP는 가입·로그인 때 이용자가 서버가 관찰한 주소를 확인하고, 기기 등록 제한·보안 이벤트·네트워크 위험 평가를 처리하는 데 사용됩니다. IP와 기기 식별자는 개인 또는 장치를 식별할 수 있는 정보가 될 수 있으므로 개인정보 처리방침에 목적과 보유기간을 공개합니다. 이는 신원을 인증하는 공식 수단이 아닙니다.

    6. COMPIVOX는 어떤 목적으로 만들어졌나요?

    개발 프로젝트를 분석하고 필요한 로컬 개발 도구를 확인하여 프로젝트별 빌드 프로세스로 Windows EXE를 생성·패키징하는 데스크톱 도구입니다. 파일 확장자만 바꾸는 프로그램은 아닙니다. 실제로 가능한 빌드는 프로젝트와 환경에 따라 달라집니다. 자세한 내용은 서비스 운영 및 개발 안내를 확인하십시오.

    7. 프로그램이 악성코드나 불법 프로그램은 아닌가요?

    서비스 목적은 프로젝트 빌드·패키징입니다. 그러나 이 설명만으로 다운로드 파일의 안전성, 모든 결과물의 무해성 또는 공인 인증을 보증할 수는 없습니다. 독립 보안 인증이나 악성코드 무검출 인증은 확인되지 않았습니다. 공식 사이트에서 파일을 받고, 실행 파일을 보안 도구로 검사하며, 출처를 모르는 프로젝트나 빌드 스크립트를 실행하지 마십시오. 앱은 작업 복사본 동의를 요구하지만 Windows Sandbox를 자동 실행하지 않습니다.

    8. 결제와 PRO 권한은 어떻게 관리되나요?

    현재 Stripe·Polar 등의 결제 연결이나 자동 구독·평생 이용권 판매는 없습니다. 서버 코드는 관리자 수동 PRO 부여와 만료 시각을 지원합니다. 공개된 가격이나 판매가 이루어지고 있다고 해석하지 마십시오. 향후 결제가 도입되면 결제 전 가격, 제공 범위, 취소·청약철회·환불 조건을 별도로 안내해야 합니다.

    9. 프로젝트 파일은 안전하게 처리되나요?

    프로젝트 소스와 빌드 자체는 로컬 PC에서 처리되고 소스 업로드·서버 빌드 기능은 확인되지 않았습니다. 빌드 권한 확인 시 계정·기기 정보, IP, 프로젝트 이름은 서버에 전달될 수 있습니다. 빌드 스크립트와 패키지 관리자는 임의 명령 실행이나 외부 네트워크 통신을 할 수 있으므로, 복사본 사용이 샌드박스 보호를 뜻하지 않습니다. 신뢰할 수 있는 프로젝트만 빌드하고 중요한 파일을 백업하십시오.

    10. 문제가 발생하면 어디에 문의해야 하나요?

    일반 기능·코드 문의는 COMPIVOX GitHub 이슈를 이용할 수 있습니다. 이슈는 공개될 수 있으므로 비밀번호, IP, 계정 정보, 개인정보 또는 비밀키를 올리지 마십시오. 개인정보 열람·삭제 등 권리 요청용 비공개 문의처는 운영자가 지정해야 하며 현재 코드에서 확인되지 않습니다. 개인정보 침해 상담은 한국인터넷진흥원 개인정보침해 신고센터의 공식 안내를 이용할 수 있습니다.
