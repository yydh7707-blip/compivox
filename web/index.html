제품 소개

프로젝트를 분석하고, 알맞게 빌드하고, EXE로 묶습니다

COMPIVOX는 단순히 파일 확장자를 바꾸는 도구가 아닙니다. 프로젝트의 언어와 구조를 분석하고, 필요한 빌드 환경이 갖춰져 있는지 확인한 뒤, 적절한 도구로 Windows 실행 파일을 생성하고 패키징합니다.

사용 방법

다섯 단계로 끝납니다

  1. 01

    Import Project

    프로젝트 파일 또는 폴더를 선택합니다.

  2. 02

    Analyze Environment

    프로젝트 언어, 구조, 의존성 및 필요한 빌드 환경을 분석합니다.

  3. 03

    Configure Build

    EXE 이름, 아이콘, 아키텍처 등 지원되는 옵션을 설정합니다.

  4. 04

    Build Application

    적절한 빌드 도구를 사용해 프로젝트를 빌드합니다.

  5. 05

    Export Executable

    생성된 결과물을 확인하고 저장합니다.

FAQ

자주 묻는 질문

COMPIVOX는 무엇인가요?

프로젝트를 분석하고 필요한 빌드 환경을 확인한 뒤, Windows EXE를 생성하고 패키징하는 데스크톱 프로그램입니다.

어떤 파일을 지원하나요?

Python, C#/.NET, C/C++, Java, Go, Rust 프로젝트는 지원됩니다. JavaScript/TypeScript 웹 프로젝트와 React/Vue/Svelte는 부분 지원이며, 일부 확장자는 단독 프로그램이 아닌 리소스로 취급됩니다.

모든 프로젝트를 EXE로 만들 수 있나요?

아니요. 지원 상태가 Supported 또는 Partial Support인 프로젝트만 빌드할 수 있으며, 프로젝트 구조에 따라 실패할 수 있습니다.

빌드 도구가 설치되어 있지 않으면 어떻게 하나요?

분석 화면에서 필요한 도구가 표시됩니다. 안내에 따라 해당 도구를 설치한 뒤 다시 분석하면 됩니다.

생성된 EXE는 어디에 저장되나요?

기본적으로 문서 폴더의 DEX Output 폴더에 저장되며, 설정에서 변경할 수 있습니다.

무료 버전과 PRO 버전의 차이는 무엇인가요?

PRO 혜택은 아직 확정되지 않았습니다. 확정되면 요금제 섹션에 안내합니다.
