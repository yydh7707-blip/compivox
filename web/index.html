About COMPIVOX

Analyze a project, build it correctly, and package it as an EXE

COMPIVOX is more than a file-extension converter. It analyzes your project's language and structure, checks that the required build environment is available, and then creates and packages a Windows executable with a suitable tool.

How it works

Five steps to finish

  1. 01

    Import Project

    Select a project file or folder.

  2. 02

    Analyze Environment

    Check the project language, structure, dependencies, and required build tools.

  3. 03

    Configure Build

    Set the EXE name, icon, architecture, and other supported options.

  4. 04

    Build Application

    Build the project with the appropriate build tool.

  5. 05

    Export Executable

    Review the output and save it.

Accounts & security

One account for the website and the app

Sign in to COMPIVOX on the web or in the Windows app with the same account. Every permission check happens on our server.

Email verification

New accounts must confirm a 6-digit code sent to their email before they can use COMPIVOX.

Cloudflare Turnstile

Turnstile is used to reduce automated requests on sign-up, sign-in and other sensitive actions.

IP and network checks

Your IP address is used for access security, network risk assessment and device registration limits. It is an extra check, not proof of identity.

Device management

Each installation gets a random Device ID. You can see and remove your devices from your dashboard.

FAQ

Frequently asked questions

What is COMPIVOX?

COMPIVOX is a desktop program that analyzes your project, checks the required build environment, and then creates and packages a Windows EXE.

Which project types are supported?

Python, C#/.NET, C/C++, Java, Go, and Rust projects are supported. JavaScript/TypeScript web projects and React/Vue/Svelte are partially supported, and some file types are treated as resources rather than standalone programs.

Can every project be turned into an EXE?

No. Only projects marked Supported or Partial Support can be built, and a build can still fail depending on the project structure.

What if the build tools are not installed?

The analysis screen shows which tools are missing. Install them as guided, then analyze the project again.

Where is the generated EXE saved?

By default it is saved in the DEX Output folder under your Documents folder. You can change this in Settings.
