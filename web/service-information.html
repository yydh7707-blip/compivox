COMPIVOX — 서비스 운영 및 개발 안내

기준일: 2026년 11월 2일

이 문서는 저장소의 현재 코드와 설정을 바탕으로 작성했습니다. 실제 운영 배포·계정 설정이 확인되지 않은 경우에는 그 사실을 별도로 적었습니다. 미구현 기능, 인증 또는 실적을 운영 중인 것처럼 표시하지 않습니다.

목차

    1. 서비스 소개

    COMPIVOX는 프로그래밍 프로젝트를 분석하고 Windows EXE로 빌드·패키징하는 과정을 지원하는 데스크톱 소프트웨어입니다. 단순히 파일 확장자만 바꾸지 않고 프로젝트 언어와 구조, 알려진 의존성 및 설치된 개발 도구를 확인한 뒤 프로젝트별 빌드 도구를 실행하는 것을 목표로 합니다. 결과는 프로젝트와 로컬 환경에 따라 달라지며 모든 프로젝트의 성공을 보장하지 않습니다.

    2. 기능 상태

    현재 코드에 구현된 기능

    • 파일·폴더를 분석하여 프로젝트 종류와 진입점 후보를 찾고 의존성·빌드 요구사항을 확인합니다.
    • 지원되는 빌드 도구와 SDK의 존재·버전을 탐지하고 프로젝트별 처리기를 선택합니다.
    • Python, .NET, C/C++, Java, Go, Rust 및 일부 웹·스크립트 프로젝트의 로컬 빌드·패키징 경로가 있습니다. 정확한 지원 등급은 앱 내 호환성 결과와 홈페이지 지원 기술 안내를 확인하십시오. PHP·Ruby는 API 지원 목록에서 예정 상태이며 일반 지원으로 보장하지 않습니다.
    • 빌드 로그·결과를 앱에서 확인하고, 계정 대시보드에서 기기·세션·요금제·빌드 이용 정보를 확인합니다.
    • 가입·로그인에는 아이디·비밀번호, 서버 관찰 IP 확인 및 Cloudflare Turnstile을 통한 서버 측 사람 확인 흐름이 구현되어 있습니다.

    현재 제공하지 않거나 확인되지 않은 기능

    • 서버로 프로젝트를 업로드하여 원격 빌드하는 기능은 확인되지 않았습니다.
    • Stripe·Polar 등 온라인 결제, 자동 구독, 평생 이용권 판매는 연결되어 있지 않습니다. PRO는 관리자가 수동으로 부여할 수 있습니다.
    • 독립 보안 인증, 악성코드 무검출 인증, 자동 실행 샌드박스, 모든 프레임워크에 대한 성공 보장은 없습니다.

    3. 프로젝트 파일 처리

    • 처리 장소: 앱을 실행하는 Windows PC의 로컬 파일 시스템과 로컬 설치 빌드 도구입니다. 원본 프로젝트를 선택하고 작업용 복사본을 만들며, node_modules, .git, 일부 가상환경·빌드 출력 폴더 등은 복사에서 제외합니다.
    • 서버 전송: 프로젝트 소스나 빌드 결과물 자체를 서버로 보내는 기능은 코드에서 확인되지 않았습니다. 다만 로그인·기기·빌드 권한 확인을 위해 계정 식별 정보, Device ID, 현재 IP와 프로젝트 이름(최대 80자)이 API에 전달될 수 있습니다.
    • 빌드·저장: 선택된 빌드 도구는 PC에서 프로젝트 복사본을 빌드합니다. 생성 결과는 이용자가 설정한 로컬 출력 폴더에 복사되며, 빌드 이력·로그도 이용자 PC의 COMPIVOX 데이터 폴더에 저장될 수 있습니다.
    • 삭제: 정상적인 빌드 종료 때 앱은 작업용 복사본을 정리합니다. 비정상 종료나 PC 오류 후에도 임시 파일이 절대 남지 않는다고 보장할 수 없습니다.
    • 외부 서비스: 로컬 빌드 도구·패키지 관리자가 SDK 다운로드나 의존성 복원을 위해 각 공급자에 요청할 수 있습니다. 이는 프로젝트 원격 빌드 기능과 다르지만, 해당 도구의 자체 네트워크·개인정보 처리에는 각 공급자 조건이 적용됩니다.

    4. 보안 및 안정성

    프로젝트 파일과 빌드 스크립트는 신뢰할 수 없는 입력으로 취급해야 합니다. 프로젝트의 빌드 스크립트, 생성기 또는 패키지 설치 절차가 임의 명령을 실행할 수 있습니다. 앱은 격리된 작업 복사본 사용에 대한 동의를 요구하지만, 코드상 Windows Sandbox를 자동 실행하지 않으며 별도 권한 격리 보장을 하지 않습니다. 신뢰할 수 있는 프로젝트만 사용하고, 중요한 파일을 백업하며, 권한이 낮은 계정과 최신 개발 도구로 빌드하십시오.

    복사 과정은 일부 큰 파일·재분석점 링크와 알려진 생성 폴더를 건너뛰며, 빌드 프로세스마다 실제 안전성이 달라질 수 있습니다. 이것을 보안 샌드박스나 악성코드 검사로 오해해서는 안 됩니다. 오류 시 개발자 로그가 로컬에 기록될 수 있으므로 공유 전에 비밀값·개인정보를 확인하십시오.

    5. 계정·네트워크·요금제 운영

    가입 시 아이디와 비밀번호를 받고, 이메일은 입력받지 않습니다. 사용자가 서버가 관찰한 IP를 직접 입력해 확인하도록 요구하며, IP는 네트워크·기기 제한과 보안 목적으로 사용됩니다. Cloudflare Turnstile 검증은 Worker에서 Cloudflare Siteverify로 수행하도록 구성되어 있습니다. Render 원본은 Worker 공유 비밀값을 요구하도록 코드가 구성되어 있습니다.

    저장소에는 Worker 경로와 Render 배포 설정이 있으나 실제 운영 배포, Cloudflare D1 생성·이관, 비밀값·DNS 설정은 여기서 확인할 수 없습니다. 개인정보 처리방침의 확인 항목을 참고하십시오. 기본 FREE 한도는 월 10회이며 설정으로 변경될 수 있습니다. PRO는 수동 관리 권한이며 결제 기능은 연결되지 않았습니다.

    6. 운영 투명성

    COMPIVOX는 정부기관·공인 인증기관·보안 인증기관이 아닙니다. 코드·설정에서 확인되지 않은 사업자 자격, 인증서, 고객 수·실적 또는 독립 보안 인증을 주장하지 않습니다. 오픈소스 빌드 도구와 외부 SDK는 각 권리자와 라이선스 조건에 따릅니다. 서비스 운영자의 법적 성명·주소·비공개 문의처는 운영자가 게시 전에 기재해야 합니다.

    7. 문의와 신고

    일반적인 코드·기능 문의는 COMPIVOX GitHub 이슈를 이용할 수 있습니다. 이슈가 공개될 수 있으므로 개인정보, 비밀번호, IP, 소스 코드의 비밀값을 게시하지 마십시오. 개인정보 권리 요청을 위한 비공개 문의 채널은 운영자 확인이 필요합니다.
