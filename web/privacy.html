Privacy Policy / 개인정보 처리방침

Last updated: draft. Describes what the service actually processes today; have it reviewed before commercial launch. / 현재 실제로 처리하는 정보를 설명하는 초안입니다. 상업 출시 전에 검토를 받으세요.

1. Data we process / 처리하는 정보

  • Email address and a salted Argon2id hash of your password (we never store the password itself). / 이메일 주소와 비밀번호의 Argon2id 해시(비밀번호 원문은 저장하지 않음).
  • IP address and sign-in history (time, result, client type). / IP 주소와 로그인 기록(시각, 결과, 클라이언트 유형).
  • Device ID (random, generated by the app), device name, registration IP and last-seen time. / 기기 ID(앱이 무작위 생성), 기기 이름, 등록 IP, 마지막 접속 시각.
  • Session records (hashed refresh tokens, IP, user agent). / 세션 기록(해시된 리프레시 토큰, IP, 사용자 에이전트).
  • Security events and build counts for plan limits. / 보안 이벤트와 요금제 한도를 위한 빌드 횟수.

2. Why / 사용 목적

Authentication, abuse prevention, network risk assessment, device and plan limits, and sending verification emails. / 인증, 남용 방지, 네트워크 위험 평가, 기기·요금제 한도 적용, 인증 이메일 발송.

3. Third parties / 제3자

  • Cloudflare Turnstile — receives challenge data from your browser and your IP when verifying. / 확인 시 브라우저의 챌린지 데이터와 IP를 처리합니다.
  • IP intelligence provider (ipapi.is, when enabled) — receives your IP address to classify the network. / 활성화된 경우 네트워크 분류를 위해 IP 주소를 전달받습니다.
  • Email (SMTP) provider — receives your email address and the message to send codes. / 코드 발송을 위해 이메일 주소와 메시지를 전달받습니다.
  • Hosting provider (Render) and, if used, Cloudflare proxy. / 호스팅 제공자(Render) 및 사용 시 Cloudflare 프록시.

4. Retention and deletion / 보관 및 삭제

Network assessments are cached for 6 hours. Device registrations by IP are kept for 90 days. Contact us to request deletion of your account data. / 네트워크 평가는 6시간 캐시되며, IP별 기기 등록 기록은 90일간 유지됩니다. 계정 데이터 삭제는 문의를 통해 요청하세요.

5. Cookies / 쿠키

A single HttpOnly cookie keeps you signed in on the website. The language choice is stored in your browser's local storage. / 웹사이트 로그인 유지를 위해 HttpOnly 쿠키 1개를 사용하며, 언어 설정은 브라우저 로컬 저장소에 저장됩니다.
