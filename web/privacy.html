목차

    1. 개인정보 처리자와 적용 범위

    이 방침은 COMPIVOX Windows 데스크톱 프로그램, 계정 웹사이트 및 계정 API에서 현재 코드로 확인되는 개인정보 처리에 적용됩니다. 코드 저장소만으로 실제 서비스 배포 여부, 운영자 법인·개인, 처리 장소를 확인할 수 없는 부분은 별도로 표시합니다.

    개인정보 처리자(운영 주체)의 법적 성명·상호와 주소: 운영자 확인 필요. 문의 담당자 및 비공개 연락처: 운영자 확인 필요.

    2. 처리하는 개인정보 항목과 목적

    목적처리 항목(코드에서 확인)처리 방식·참고
    계정 생성·로그인·세션 유지계정 아이디, 비밀번호 해시, 계정 내부 식별번호, 로그인 성공·실패와 사유, 접속 시각·IP·클라이언트 유형, User-Agent비밀번호 원문은 저장하지 않습니다. 해시는 환경에 따라 Argon2id 또는 scrypt를 사용하며 갱신 토큰은 해시해 저장합니다. 웹 로그인은 HttpOnly 세션 쿠키, 데스크톱은 DPAPI로 보호된 갱신 토큰을 사용합니다.
    기기 연결 및 권한 확인무작위 Device ID, 사용자가 연결하는 기기 이름(기본값으로 Windows 컴퓨터 이름), 등록·최근 접속 IP와 시각계정·기기 수 및 네트워크별 등록 제한과 기기 관리에 사용합니다.
    접근 보안·남용 방지클라이언트 IP, User-Agent, 요청 횟수 제한용 해시 식별자, 네트워크 위험 평가 결과와 접속 보안 이벤트IP 위험정보 제공자 키가 설정된 경우에만 ipapi.is에 평가 대상 IP를 요청합니다. 결과에는 VPN·프록시 등 분류, ASN·조직 정보가 포함될 수 있습니다.
    요금제·빌드 한도 관리FREE/PRO 권한, 권한 출처·만료 시각, 빌드 월·시각, 요청된 프로젝트 이름(최대 80자), 연결된 Device ID프로젝트 소스 파일이나 빌드 결과물은 계정 API에 업로드되지 않습니다. 프로젝트 이름은 데스크톱 앱에서 빌드 권한을 요청할 때 API에 전송됩니다.
    Cloudflare 보안 확인Turnstile 검증 시 브라우저 챌린지 정보와 IP, 일회용 확인 ID·토큰의 해시, 요청 제한 키의 해시, 만료·사용 시각원본 Turnstile 토큰은 D1에 저장하지 않습니다. 확인 기록과 제한 기록은 요청 처리 과정에서 정리되지만 정기 작업은 확인되지 않았습니다.

    신규 가입 화면은 이메일을 입력받지 않습니다. 현재 가입 코드는 데이터베이스 호환을 위해 무작위 @users.compivox.invalid 형식의 내부 이메일 값을 생성합니다. 데이터베이스에는 이메일 열이 남아 있으며 과거 계정에 실제 이메일이 있는지는 운영자가 기존 계정을 확인해야 합니다. 비밀번호 분실 이메일 발송 기능은 제거되어 있습니다.

    고객 문의 내용, 결제 식별정보, 신용카드 정보는 현재 구현된 문의·결제 기능에서 수집하지 않습니다. 온라인 결제는 연결되어 있지 않습니다.

    가입 시 이용약관 버전, 개인정보 처리방침 버전 및 동의 시각을 계정과 연결해 기록합니다. 접속·보안 오류의 상세 내용은 서버 콘솔에 기록될 수 있습니다. Cloudflare·Render 등 호스팅 업체의 자체 접속 로그 항목과 보유기간은 운영 계정에서 확인해야 합니다.

    3. 수집 방법

    • 가입·로그인·기기 연결 과정에서 아이디, 비밀번호, IP 확인값, 기기 이름 등을 이용자가 입력하거나 확인합니다.
    • 웹 서버와 API는 요청 처리 과정에서 접속 IP, User-Agent, 시각 및 보안·계정 이벤트를 자동 기록합니다.
    • 데스크톱 앱은 무작위 Device ID를 생성해 Windows 사용자 범위 DPAPI로 보호하여 로컬에 저장합니다. 앱은 로그인·기기·빌드 권한 확인을 위해 필요한 계정 정보와 프로젝트 이름을 API에 보냅니다.
    • Cloudflare Turnstile과, 설정된 경우 ipapi.is가 해당 기능에 필요한 정보를 처리할 수 있습니다.

    4. 보유 및 이용 기간

    • 계정·비밀번호 해시·요금제 정보: 계정이 유지되는 동안. 다만 현재 공개된 코드에는 이용자 셀프 계정 삭제 기능이 없고, 계정 및 관련 기록의 일괄 파기 절차와 기간은 운영자가 확정해야 합니다.
    • 세션: 갱신 토큰 유효기간은 기본 30일이며 만료·철회 처리합니다. 만료된 DB 행의 정기 삭제 작업은 확인되지 않았습니다.
    • IP별 기기 등록 제한: 판정에는 최근 90일 기록을 사용하지만, 그보다 오래된 행을 자동 삭제하는 작업은 확인되지 않았습니다.
    • 로그인·빌드 이용·위험 평가·보안 이벤트 기록: 일부 대시보드는 최근 항목만 조회하지만, 코드에 전체 기록의 자동 보유기간·정기 파기 작업은 확인되지 않았습니다. 단순히 화면에서 숨겨지는 것이 삭제를 뜻하지 않습니다.
    • Cloudflare D1의 일회용 확인 기록은 5분 만료로 생성되고 사용 후 정리 대상이 됩니다. 요청 제한 기록도 과거 창을 정리하도록 되어 있으나 둘 다 후속 요청 시 실행되는 정리이며 정기 스케줄은 확인되지 않았습니다.

    필수 운영 조치: 계정 탈퇴·삭제 접수와 본인 확인 절차를 마련하고, 위 각 기록의 법적 보유 근거와 파기 시점·자동 삭제 일정을 운영자가 확정하여 이 방침을 갱신해야 합니다. 현재 지원 채널은 공개 GitHub 이슈뿐이므로 개인정보가 포함된 삭제 요청을 공개 이슈에 올리지 마십시오. 비공개 문의 수단을 마련하기 전에는 안전한 개인정보 권리 행사가 보장된다고 안내할 수 없습니다.

    5. 개인정보의 제3자 제공

    확인된 코드에는 개인정보를 광고·판매 목적으로 제3자에게 제공하는 기능이 없습니다. Cloudflare, Render 및 설정 시 ipapi.is는 기능 제공 과정에서 데이터를 처리하는 서비스 제공자로 파악되며, 이는 제3자 제공과 구분하여 아래 위탁·국외 이전 항목에 설명합니다. 실제 계약·수신자·제공 관계는 운영자가 확인해야 합니다. 법령에 근거한 제공 등 법률상 예외가 적용되는 경우에는 그 법령에 따릅니다.

    6. 개인정보 처리 업무의 위탁

    • Cloudflare: Worker·정적 자산·D1·Turnstile 기능의 코드와 설정이 있습니다. 웹 호스팅, API 게이트웨이, 봇 확인 및 단기 확인·요청 제한 기록 처리. 실제 운영 배포 여부와 계약상 수탁 법인·처리 항목·보유기간 확인 필요.
    • Render: 계정 API와 SQLite 영속 디스크를 위한 배포 설정이 있습니다. 계정·세션·기기·로그 데이터 호스팅. 서비스 설정에 배포 지역이 지정되어 있지 않아 실제 지역 및 수탁 법인·보유기간 확인 필요.
    • ipapi.is: IP_INTELLIGENCE_API_KEY가 설정된 경우에만 네트워크 분류를 위해 IP를 전송합니다. 운영 환경에서 키가 설정되었는지와 제공자의 처리 조건을 확인해야 합니다.

    현재 Stripe, Polar 또는 다른 결제 대행업체 연동은 확인되지 않았습니다. 위 업체의 실제 계약·처리자 정보는 소스 코드만으로 확정할 수 없습니다.

    Cloudflare와 Render가 자체 서비스 운영을 위해 처리하는 요청·진단 로그의 구체 항목과 기간은 이 저장소에서 설정되지 않았습니다. 운영자는 계약·관리 콘솔 및 각 제공자 고지를 확인해야 합니다.

    7. 개인정보의 국외 이전

    Cloudflare Turnstile은 Cloudflare의 외부 서비스에 검증 요청을 하고, 사이트는 Cloudflare Worker·D1 사용을 구성합니다. Render와 ipapi.is도 외부 호스팅·위험 분류 서비스로 구성되어 있습니다. 따라서 국외에서 처리될 가능성을 배제할 수 없지만, 실제 계정의 수신 법인, 이전 국가·위치, 이전 시점·방법, 항목, 보유기간 및 적용 근거는 저장소에서 확인할 수 없습니다.

    운영자는 실제 배포·계약 설정에 따라 개인정보 보호법상 국외 이전 해당 여부와 고지·동의 등 필요한 절차를 검토하고, 수신자·국가·항목·목적·기간·거부 방법을 확인하여 이 항목을 구체화해야 합니다. 현재 확인되지 않은 국가나 법인을 사실처럼 적지 않습니다.

    8. 개인정보의 파기

    계정 DB는 SQLite 영속 디스크에 저장됩니다. 코드에는 이용자가 계정을 삭제하는 기능이나 데이터 전체를 정기 파기하는 스케줄러가 확인되지 않았습니다. 계정 삭제 요청이 접수되면 신원 확인, 삭제 대상·법정 보존 예외 확인, 원본 및 백업·로그의 파기 범위와 완료 통지를 포함하는 절차를 운영자가 마련해야 합니다. 현재 구현되지 않은 파기 절차를 운영 중이라고 표시하지 않습니다.

    데스크톱 빌드는 프로젝트의 임시 작업 복사본을 작업 종료 시 코드의 정리 절차로 삭제하고, 결과물과 빌드 기록·로그는 이용자 PC에 남습니다. 갑작스러운 전원 종료·프로세스 강제 종료 등 비정상 상황에서 임시 파일이 남을 가능성을 배제할 수 없습니다.

    9. 정보주체와 법정대리인의 권리

    이용자는 적용 법령에 따라 개인정보 열람·정정·삭제·처리정지 등을 요청할 수 있습니다. 법정대리인은 법령이 정하는 범위에서 미성년자의 권리를 행사할 수 있습니다. 코드에는 웹 대시보드에서 기기 해제와 세션 로그아웃은 있으나 계정 삭제·개인정보 열람 사본 요청 절차는 구현되어 있지 않습니다.

    현재 공개 지원 경로는 GitHub 이슈입니다. 이슈는 공개될 수 있으므로 비밀번호, IP 주소, 신분증, 계정 식별 정보 등 개인정보를 게시하지 마십시오. 비공개 개인정보 문의 연락처는 운영자가 지정해야 하며, 이를 마련하기 전에는 권리 요청 경로가 불완전합니다.

    10. 쿠키·로컬 저장소와 자동 수집 장치

    웹 로그인은 cvx_rt라는 HttpOnly, SameSite=Strict 세션 쿠키를 사용하며 보안 연결에서는 Secure 속성을 적용합니다. 언어 선택은 브라우저 localStorage에 저장됩니다. 분석·광고 추적 스크립트는 현재 웹 소스에서 확인되지 않았습니다. Cloudflare Turnstile을 불러오므로 해당 외부 서비스가 챌린지 제공 과정에서 정보를 처리할 수 있습니다.

    쿠키를 차단하면 웹 로그인 유지 등 일부 기능이 작동하지 않을 수 있습니다. 브라우저 설정에서 쿠키 및 로컬 저장소를 삭제할 수 있습니다. 외부 제공자의 쿠키·유사 기술 및 opt-out 조건은 실제 서비스 계약과 제공자 고지를 확인해야 합니다.

    11. 개인정보 안전성 확보 조치

    코드에서 확인되는 조치는 비밀번호 해시 저장, 웹 세션 HttpOnly 쿠키, 데스크톱 갱신 토큰·기기 ID의 Windows DPAPI 보호, JWT 기반 세션, 요청 제한, Cloudflare 서버 측 Turnstile 검증, Worker와 Render 원본 간 공유 비밀값 확인, HTTPS를 전제로 한 배포 설정입니다. 빌드 도구가 임의 스크립트를 실행할 수 있음을 앱에서 알리고 동의를 받습니다.

    독립 보안 인증·침투 시험·전용 샌드박스 실행 또는 무결점 보장은 확인되지 않았습니다. 운영자 접근통제·백업 암호화·침해 대응·취약점 점검 정책도 코드만으로 확인할 수 없으므로 시행 중이라고 단정하지 않습니다.

    12. 개인정보 보호책임자와 문의
